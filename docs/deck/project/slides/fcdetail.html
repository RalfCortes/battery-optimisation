Forecast set-up in detail

ItemSetting (config/forecast.yaml)
ModelChronos-2 zero-shot, 21 native quantiles, 28-day context, GPU
Issue timeAt gate closure, 2 intervals before delivery; every half-hour (rolling 48 steps)
Known covariatesCalendar (time of day, weekday, holiday), price-cap regime flag, weather
Past-only covariatesSystem demand (no archived demand forecasts yet)
WeatherECMWF IFS 06Z/18Z runs, 3×3 grid around Singapore; temperature, humidity, cloud, irradiance, rain
Weather “as of”For issue T: the latest run r with r + availability delay ≤ T. Never the “previous day” series (published later)
TargetsUSEP and the regulation, primary and contingency prices (group A)
Leakage rulebuild_input only takes data strictly before the issue time; tested

Walk-forward: everything fitted for month M (copula, persistence) uses issues realised before M only

Weather runs are downloaded paced and resumable (429 backoff); a missing run falls back to the latest usable older run and is counted in the report.
